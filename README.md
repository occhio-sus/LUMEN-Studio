# 💡 Lumen — AI Study Companion

**Lumen** è un'applicazione web minimale, ultra-veloce e sicura progettata per trasformare i tuoi appunti e le tue foto di studio in risorse di apprendimento interattive (Riassunti, Flashcard 3D, Quiz/Indovinelli e Podcast Audio).

![Lumen Preview](https://images.unsplash.com/photo-1516321318423-f06f85e504b3?q=80&w=1200&auto=format&fit=crop)

---

## ✨ Funzionalità Principali

- 💬 **Interfaccia Chat Fullscreen**: Esperienza di studio immersiva e immediata.
- 📸 **Multimodale**: Carica foto di appunti, PDF o scrivi direttamente il testo.
- 🎴 **Flashcard Interattive**: Animazioni 3D per lo studio con ripetizione attiva.
- 🧩 **Quiz & Indovinelli**: Generazione automatica di domande di verifica.
- 🎙️ **Podcast Audio**: Pillole audio di ripasso riproducibili ovunque.
- 🔒 **Sicurezza Avanzata**: Sanitizzazione anti-XSS, isolamento input e controlli rigorosi sui file.
- ⚡ **Prestazioni Instant-Load**: Avvio istantaneo con ottimizzazione delle risorse.
